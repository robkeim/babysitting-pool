# Frontend is a client-only SPA on TanStack Router and Query, with ESLint as the single lint gate

The frontend stays a client-only React + Vite + Tailwind 4 + shadcn (Base UI) SPA: members are logged in, so SSR and SEO buy nothing. On top of it we use TanStack Router (typed paths and search params, so agents' wrong links fail at compile time), TanStack Query for all server state, and React Hook Form + Zod for forms, where Zod only gives fast feedback and the backend domain stays authoritative. There is no global store library; shareable UI state lives in URL search params. Component tests are Vitest + RTL + user-event with MSW mocking the REST API.

We chose ESLint (flat config, `typescript-eslint` strict-type-checked, `react-hooks`, `jsx-a11y`, import-boundary rules) over oxlint and Biome because the requirement is strong, build-failing rules, and ESLint has the deepest type-aware and architecture-enforcing rules. Warnings are not allowed (`--max-warnings 0`), and Prettier handles formatting. Running oxlint alongside ESLint was rejected as two configs for a speed gain this project won't feel. TypeScript runs with explicit `strict` and `noUncheckedIndexedAccess`.
