# The REST contract is OpenAPI-first with cookie sessions on a single origin

The backend emits the OpenAPI document, which is committed (`docs/api/openapi.json`) and checked for drift in CI. The frontend generates DTO types from the committed file with `openapi-typescript`, and keeps the hand-written fetch wrapper and per-feature Query hooks (ADR 0005). Generators that emit clients or hooks (Orval, hey-api) were rejected because they collide with those rules. A Postman collection is generated from the same file, committed, and also drift-checked in CI, which requires deterministic generation (stable ordering, no timestamps or random ids).

Sessions are HttpOnly, Secure, SameSite=Lax cookies, and the SPA and API share one origin: the Vite dev proxy forwards `/api` locally, and one host serves both in production. This removes CORS and cross-site cookie problems entirely. CSRF is defended by requiring a custom header (`X-Requested-With`) on state-changing calls, with an API test asserting a missing header is rejected with 403. A bearer token in JS storage was rejected.

Every non-2xx response is `application/problem+json` with a stable machine-readable `code`; `title` and `detail` are English developer text that the frontend never displays, so i18n keys off `code`. Statuses: 400 malformed input (with an `errors` map of field to codes), 401 not signed in, 403 not an Admin or missing CSRF header, 409 state conflicts (lost first claim, Request no longer Posted), 422 domain rule violations (insufficient credits, below Minimum Lead Time).

Routes are resource-oriented under `/api/...`, with domain verbs as POST sub-resources (`POST /api/requests/{id}/claim`). Credits are integer quarter-credits in `...QuarterCredits` fields (ADR 0001), timestamps are ISO-8601 UTC, ids are GUIDs, and lists return `{ items, nextCursor }`. There is no API versioning: one client deploys with the API. Admin endpoints live under `/api/admin/...`; `POST /api/admin/settle` exists in production, is Admin-only, idempotent, and takes no timestamp. Test-only clock and outbox endpoints stay E2E-only.
